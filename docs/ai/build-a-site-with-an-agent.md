## What you will build

A small site, such as a site for a local business, built by an agent from a short written brief, and reviewed by you before anything is published.

What you will need: a WordPress site you can experiment on (a local site or a WordPress Playground site), an agent, and a way to connect it. See [Connect an AI agent to your site](connect-an-agent.md).

How to describe the site you want: its purpose, its pages, its tone, and what the agent must not change.

## Let the agent draft the site

What the agent will do: choose or configure a theme, create pages from patterns, and draft content, all as drafts.

# Users and roles

A WordPress site can have many users, and each user has a role that decides what they can do, from reading private posts to changing every setting. Administrators add users, assign roles and remove users from the **Users** screen.

Start with [Roles and capabilities](roles-and-capabilities.md) to choose the right role, then [Add a user](add-a-user.md).

# Manage your site

This section helps you run a WordPress site after it is built. It covers the dashboard and its screens, the settings, the people who can log in and what each of them can do, plugins, updates, security, privacy and troubleshooting. Most of these tasks need the Administrator role. If you are looking for a screen by its name in the admin menu, start with [Dashboard and admin screens](dashboard/README.md).

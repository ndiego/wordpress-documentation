# WordPress documentation

This documentation helps you build and run a website with WordPress. It covers the software you install on your own hosting, as it works in a current release: writing in the block editor, designing with a block theme and the Site Editor, and managing users, settings, updates and security.

If you are new, start with Get started and read it in order; it takes you from "what is WordPress?" to a published site. If you came to do one thing, go straight to the section for that task and search from there. Every page says what you will be able to do after reading it.

AI assistants and agents can read every page as Markdown at its URL plus `.md`, and find the full index at `/llms.txt`.

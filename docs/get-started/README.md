# Get started

After this section you can explain what WordPress is, get a site running, and find your way around it. The pages form one path: what WordPress is, where to run it, how to install it, a guided first session, and how a site is put together. Read them in order if WordPress is new to you. If you already have a site, skip ahead to [Your first site](your-first-site.md) or [How a WordPress site is put together](how-wordpress-works.md).

# Classic WordPress

Using WordPress without the block editor and the Site Editor: the Classic Editor plugin, and the Customizer, Widgets and Menus screens that classic themes use.

- [Classic Editor](classic-editor/README.md): The Classic Editor plugin brings back the editor WordPress used before version 5.0.
- [Widgets, Menus and the Customizer](widgets-menus-customizer/README.md): Classic themes are customised in the Customizer (Appearance > Customize) and on the Widgets and Menus screens.

The classic default themes, Twenty Twenty-One back to Twenty Ten, are in [Default themes](../design/themes/default-themes/README.md). Building classic themes is covered in [Classic themes](https://developer.wordpress.org/themes/classic-themes/) in the developer documentation.

# Classic WordPress

Before the block editor and block themes, WordPress sites were written in the Classic Editor and designed with the Customizer, widgets and menus. Many sites still work that way: those that use the Classic Editor plugin, and those with a classic theme.

This section keeps the documentation for those tools apart from the rest, so that a new site never needs it. The classic default themes, Twenty Twenty-One back to Twenty Ten, are in [Default themes](../design/themes/default-themes/README.md). Building classic themes is covered in [Classic themes](https://developer.wordpress.org/themes/classic-themes/) in the developer documentation.

# Widgets, menus and the Customizer

Classic themes are customized in the Customizer (**Appearance > Customize**) and on the **Widgets** and **Menus** screens. Block themes replace all three with the Site Editor (**Appearance > Editor**), where widget areas become template parts and menus become Navigation blocks; see [The Site Editor](../../design/site-editor/README.md).

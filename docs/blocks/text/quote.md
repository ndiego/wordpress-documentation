# Quote

Use the Quote block to easily add a quote to any post or page. Adding quotes can help you highlight great reviews from your audience or phrases that inspire you.

## Add a Quote block

To add the Quote block to a page, click the block inserter (+) to open the block inserter pop-up window and choose the *Quote* block.

![Demonstration to add the quote block to the editor](https://wordpress.org/documentation/files/2023/03/quote-block.gif)

Alternatively, you can use the slash command, `/quote` in a new paragraph block then press `enter` to add one quickly.

![Shortcut to add Quote block](https://wordpress.org/documentation/files/2020/09/Annotation-2020-09-14-120316.png)

> [!NOTE]
> [Detailed instructions on adding blocks](../../write/blocks/add-a-block.md)

## Block toolbar

Each block comes with unique toolbar icons and blocks specific user controls that allow you to manipulate the block right in the editor.

To view the block toolbar, click on the block, and the toolbar will be displayed.

![Quote block toolbar](https://wordpress.org/documentation/files/2023/03/toolbar-1.png)

The Quote block shows the following buttons:

-   Transform to
-   Drag icon
-   Move handles
-   Change text alignment
-   Bold
-   Italic
-   Link
-   More text editing options
-   Options

### Transform to

![Transform tool for the Quote Block](https://wordpress.org/documentation/files/2023/10/image-10.png)

Click on the **Transform** button to convert the *Quote* block into another block type using the existing content.

You can transform the Quote block into a **Paragraph**, **Columns**, **Group**, or **Pullquote** block. You can also change the style of the Quote block from **Default** to **Plain**.

### Drag icon

![Drag and drop tool for the Quote block](https://wordpress.org/documentation/files/2023/03/drag-1.png)

To drag and drop the block to a new location on the page template, click and hold the rectangle of dots, then drag it to the new location. The blue separator line indicates where the block will be placed. Release the left mouse button when you find the new location to place the block.

### Move handles

![Move handles for the Quote block](https://wordpress.org/documentation/files/2023/03/arrows-1.png)

The up and down arrow icons can be used to move the block up and down on the page.

> [!NOTE]
> [Get more information about moving a block within the editor.](../../write/blocks/move-blocks.md)

### Change text alignment

![Text alignment tool for the Quote block](https://wordpress.org/documentation/files/2023/03/align-1.png)

*.*

Using the alignment drop-down from the toolbar, you are able to align the *Quote* block to the left, make it center-aligned, or align it to the right.

### Bold

![Bold text tool for the Quote block](https://wordpress.org/documentation/files/2023/03/bold-2.png)

You can select the text in the *Quote* block and use the Bold option or <kbd>Ctrl+B</kbd> or <kbd>Cmd+B</kbd> on your keyboard to bold it, which is usually heavier than the surrounding text.

### Italic

![Italic text tool for the Quote block](https://wordpress.org/documentation/files/2023/03/italics.png)

You can select any text inside the Quote block and use the **Italic** option or <kbd>Ctrl+I</kbd> or <kbd>Cmd+I</kbd> on your keyboard to italicize it, which usually appears slanted to the right.

### Link

Use the link icon to insert a hyperlink to the highlighted text inside the *Quote* block.

> [!NOTE]
> [Read about more link editing options.](../../write/blocks/link-control.md)

### More rich text options

The drop-down menu to the left of the [More options menu](../../write/blocks/more-options.md) contains a range of additional rich text editing options such as highlighting, inline code, strikethrough, and more.

> [!NOTE]
> [Read about more rich text editing options.](../../write/blocks/rich-text-options.md)

### More options

The Options menu represented by three vertical dots on the far right of the toolbar gives you more features such as the ability to duplicate or remove the block.

> [!NOTE]
> [Read about these and other settings.](../../write/blocks/more-options.md)

## Block settings

The block settings panel contains customization options specific to the block. To open it, select the block and click the **Settings** button next to the **Publish/Update** button.

![Block settings button on the editor](https://wordpress.org/documentation/files/2023/03/block-settings.png)

### Styles

You can modify the Quote block styles by choosing the **Default** or **Plain** buttons in the Styles settings panel. Hover over the **Default** or **Plain** buttons to get a preview of the styles.

The style options may vary based on your theme.

![Styles option for the Quote block](https://wordpress.org/documentation/files/2023/03/styles-1.png)

### Typography

The Quote block provides typography settings to change the font family, size, appearance, line height, letter case, letter spacing, and decoration.

> [!NOTE]
> [Get more details about changing typography settings.](../../write/block-settings/typography.md)

### Background

The Background settings allow you to customize the appearance of supported blocks using background images, colors, and gradients.

> [!NOTE]
> For details, refer to the [Background Settings Overview](../../write/block-settings/background.md).

### Dimensions

The Quote block provides dimension settings options to change padding and margin size.

> [!NOTE]
> For details refer to this support article: [Dimension settings overview](../../write/block-settings/dimensions.md)

### Border

This option allows you to set a border around the block, including the color, the width, radius, and the style of the border.

> [!NOTE]
> [Learn more about Border & Shadow settings.](../../write/block-settings/border.md)

### Elements

The Elements settings allow you to customize the appearance of links, buttons, headings, and heading levels H1 through H6.

### Advanced

The Quote block provides the following Advanced settings options: HTML Anchor, Additional CSS Class(es), Additional CSS, Styles, and Allowed blocks.

> [!NOTE]
> [Learn more about advanced settings](../../write/block-settings/advanced.md)

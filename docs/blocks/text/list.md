# List

You can use the List block to create a bulleted or numbered list.

[Watch the video](https://wordpress.org/documentation/files/2019/03/list-block.webm)

## How to add the List block

Open the Block Inserter tool by clicking the **+ Block Inserter** button in the top toolbar or in the block editor. Look for the List block by using the search bar, then click the icon to insert it into the editor.

You can also click the Block Inserter (+) icon in the editor and then choose the List block in the pop-up window.

![Adding a list block with a slash command](https://wordpress.org/documentation/files/2019/03/Screenshot-2026-07-23-at-11.59.47-AM.png)

You can also use a (/) slash command by typing `/list` in the editor.

> [!NOTE]
> [Detailed instructions on adding blocks.](../../write/blocks/add-a-block.md)

Each List Item block inside the List block is a block that can be edited and moved. List Items can also be selected in the [List View](../../write/blocks/list-view.md).

## List Block toolbar

Every block comes with unique toolbar icons and block-specific user controls that allow you to manipulate the block right in the editor.

The List block shows these standard buttons:

-   Transform to
-   Block moving tools
-   Unordered list
-   Ordered list
-   Indent
-   More options

![The List Block Toolbar.](https://wordpress.org/documentation/files/2022/11/61-listblock-toolbar.png)

### Transform to

You can transform the List block into the Paragraph, Heading, Quote, Columns, or Group blocks. You can unwrap list items and replace the list with the individual blocks using the Unwrap option.

![The List block Transform to modal.](https://wordpress.org/documentation/files/2019/03/list-transforms_to-1.jpg)

### Block moving tools

![The List Block moving handles in the Toolbar.](https://wordpress.org/documentation/files/2022/11/61-listblock-toolbar-move.png)

The up and down arrow icons can be used to shift a block up and down in your document.

> [!NOTE]
> [Get more information about moving a block within the Editor](../../write/blocks/move-blocks.md).

### Unordered list

![The List Block unordered list option in the Toolbar.](https://wordpress.org/documentation/files/2022/11/61-listblock-toolbar-unordered.png)

An unordered list typically is a bulleted list of items. You can use unordered list where you do not need to display items in any particular order.

![An example of unordered list.](https://wordpress.org/documentation/files/2019/03/Untitled-111111.png)

*An example of unordered list*

### Ordered list

![The List Block ordered list option in the Toolbar.](https://wordpress.org/documentation/files/2022/11/61-listblock-toolbar-ordered.png)

An ordered list typically is a numbered list of items. You can use ordered list where you need to display items in a particular order.

![An example of ordered list.](https://wordpress.org/documentation/files/2019/03/Untitled-811111.png)

*An example of ordered list*

## List Item block toolbar

The List Item shows the following buttons:

-   Block moving tools
-   Outdent list item
-   Indent list item
-   Bold
-   Italic
-   Hyperlink
-   More rich text controls
-   More options

![The List Item Toolbar with options for moving, indenting, outdenting, bold, italic and linked text.](https://wordpress.org/documentation/files/2022/11/61-listblock-listitem-toolbar.png)

### Outdent list item

![The List Item outdent Toolbar option.](https://wordpress.org/documentation/files/2022/11/61-listblock-list-item-outdent-toolbar-1.png)

Select the list item. You can decrease the indentation level using the “Outdent list item” option, or by pressing either the `Backspace` key or `Shift+Tab` key combination – which provides a convenient way to adjust indentation using keyboard commands.

### Indent list item

![The List Item indent Toolbar option.](https://wordpress.org/documentation/files/2022/11/61-listblock-list-item-indent-toolbar-1.png)

Select the list item. You can increase the indentation level using the “Indent list item” option, or by pressing either the `Space` key or the `Tab` key – which provides a convenient way to adjust indentation using keyboard commands.

### Bold and italics

![The List Item Toolbar option for bold text.](https://wordpress.org/documentation/files/2022/11/61-listblock-listitem-bold.png)

![The List Item Toolbar option for italic text.](https://wordpress.org/documentation/files/2022/11/61-listblock-listitem-italic.png)

The Bold and Italics formatting options are used to customize the text in the block. You can also use keyboard shortcuts to enable these text formatting:

-   `Ctrl + B` or `Command + B` to bold the text.
-   `Ctrl + I` or `Command + I` to italicize the text.

### Link

You can select the text of a list item and use the Hyperlink option or <kbd>Ctrl+K / Cmd+K</kbd> on your keyboard to add a link to it.

> [!NOTE]
> [Read about more link editing options.](../../write/blocks/link-control.md)

### More rich text options

The drop-down menu to the left of the [More options menu](../../write/blocks/more-options.md) contains a range of additional rich text editing options such as highlighting, inline code, strikethrough, and more.

> [!NOTE]
> [Read about more rich text editing options.](../../write/blocks/rich-text-options.md)

## Block settings

Every block has specific options in the editor sidebar in addition to the options found in the block toolbar. If you do not see the sidebar, click on the **Settings button** next to the Save/Publish button.

![Block Settings button](https://wordpress.org/documentation/files/2020/11/block-settings-7-0.png)

### List View

![List view tab for List Block settings](https://wordpress.org/documentation/files/2019/03/list-block-list-panel.jpg)

*Screenshot*

The **List view tab**, represented by three horizontal lines, allows you to re-order single Button blocks within the Buttons block.

> [!NOTE]
> [Learn more about options and settings available in list view.](../../write/blocks/list-view.md)

### Settings

![](https://wordpress.org/documentation/files/2019/03/Screenshot-2026-07-23-at-12.15.24-PM.png)

When you select the Social Icons block **Settings tab**, represented by a gear icon, you can change settings on the List block

If you are using an ordered list, you will see settings for List style, start value, and reverse order. You will see Advanced settings for both ordered and unordered lists.

#### List style

If you choose an ordered list, you can select the list style from the List Style dropdown.

![List style of Ordered list](https://wordpress.org/documentation/files/2019/03/list-ordered-liststyle-6.8.jpg)

#### Start value

You can select the number your list starts at. This is useful if you want your list to start at a number other than 1.

#### Reverse order

You can also reverse the numbers of the list to start at the highest number first.

#### Advanced

The List block provides the following Advanced settings options: HTML Anchor, Additional CSS Class(es), Additional CSS, and Styles.

> [!NOTE]
> [Learn more about advanced settings](../../write/block-settings/advanced.md)

### Styles

The **Styles tab** is represented by a half-filled circle.

#### Unordered list settings

![Styles tab with default and checkmark options](https://wordpress.org/documentation/files/2019/03/Screenshot-2026-07-23-at-12.10.23-PM.png)

If you choose an unordered list, you can select the symbol style at the beginning of every list item from Styles. These style options may be different depending on your theme.

![unordered list with checkmark](https://wordpress.org/documentation/files/2019/03/list-unordered-checkmark-6.8.jpg)

*Unordered list with checkmark style*

#### Color

The List block provides Color settings options to change the text and background colors

> [!NOTE]
> [See this guide for more information about changing colors.](../../write/block-settings/color.md)

#### Typography

The List block provides typography settings to change the font family, size, appearance, line height, letter case, letter spacing, and decoration.

> [!NOTE]
> [Get more details about changing typography settings.](../../write/block-settings/typography.md)

#### Dimensions

The List block provides dimensions settings options to change padding and margin size.

> [!NOTE]
> [Learn more about dimension controls.](../../write/block-settings/dimensions.md)

#### Border

Border settings provide options to control the width and radius for the List block.

> [!NOTE]
> [Learn more about border & shadow settings.](../../write/block-settings/border.md)

## Individual List item settings

When you choose an individual list item, you can change the following styles: Color, typography, border and advanced. See the links above to learn more.

# Text blocks

Text blocks hold the words on a page: paragraphs and headings, lists and quotes, tables, code and poetry. Most posts are built mainly from these blocks.

Start with the [Paragraph](paragraph.md) and [Heading](heading.md) blocks; the others work the same way, with a few settings of their own.

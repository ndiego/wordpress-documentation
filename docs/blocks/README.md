# Blocks

Blocks are the pieces you build every post, page and template from. Each paragraph, image, heading or list is a block, and each block has its own toolbar and settings. WordPress ships with about a hundred of them, and plugins can add more.

This reference has one page per core block, grouped the way the block inserter groups them: text, media, design, widgets, theme and embeds. To learn the tools every block shares, such as adding, moving and styling blocks, start with [Working with blocks](../write/blocks/README.md).

## Most used blocks

You will also find a Most Used blocks category which is not shown by default. This category will be visible only if you enable ‘Show most used blocks’ in your [Preferences](../write/editor/preferences.md#blocks).

When enabled, the Most Used blocks category will be displayed right above the Text blocks category. It will list all the blocks that you used recently on your post or page.

![Most Used blocks](https://wordpress.org/documentation/files/2022/07/Screen-Shot-2022-07-21-at-2.47.01-PM.png)

> [!NOTE]
> The blocks that appear in the Most Used section will vary based on which blocks you used recently on your post or page.

| Post Comments block | 6.0 | Replaced with Comments Query Loop block |

# Theme blocks

Theme blocks build the templates of a block theme in the Site Editor. They display parts of your site that change from page to page, such as the site title, the navigation menu, a post's title, date and content, or a list of posts from a query.

You mostly meet them while editing templates; see [Templates and template parts](../../design/site-editor/templates.md) for how templates fit together.

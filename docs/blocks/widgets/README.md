# Widget blocks

Widget blocks show content that WordPress keeps up to date for you: your latest posts and comments, archives, a calendar, a tag cloud, a search form and links to your social profiles.

You can use them anywhere in a post, a page or a template, and in the widget areas of a classic theme.

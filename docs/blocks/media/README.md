# Media blocks

Media blocks put images, audio, video and files on a page, or combine media with text, as the [Cover](cover.md) and [Media & Text](media-text.md) blocks do.

Files you add through these blocks go into the Media Library, where you can reuse and edit them. See [Media](../../write/media/README.md) for how the library works.

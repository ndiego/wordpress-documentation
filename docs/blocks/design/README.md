# Design blocks

Design blocks arrange other blocks. Use them to lay out a page in columns, rows, stacks and grids, to add buttons, separators and space, and to hide content in accordions and tabs.

The [Group](group/README.md) block is the one to learn first: most layouts are groups of blocks with a layout and a few design settings applied.

# Default themes

Since 2010, WordPress has shipped a new default theme most years, named after the year it was made for. These pages describe each one, from Twenty Ten to Twenty Twenty-Five: what it looks like, the features it supports and how to customize it.

Twenty Twenty-Two and later are [block themes](../block-themes.md), which you customize in the [Site Editor](../../site-editor/README.md). Twenty Twenty-One and earlier are classic themes, which you customize with the [Customizer, widgets and menus](../../../classic/widgets-menus-customizer/README.md). You can install any of them from the [theme directory](https://wordpress.org/themes/).

# Twenty Fourteen

Twenty Fourteen was the default theme for WordPress 3.8, released in 2013. It is a magazine-style
theme with a featured content area and a dark, bold layout.

There is no full guide for this theme yet. You can see it and its demo on its [theme directory page](https://wordpress.org/themes/twentyfourteen/).

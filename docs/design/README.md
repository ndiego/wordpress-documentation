# Design your site

This section helps you change how your whole site looks. Your theme decides the look: its templates lay out each kind of page, and its styles set the colors, fonts and spacing. The Site Editor, at **Appearance > Editor**, lets you edit every part of that design with blocks, from the header and footer to the template for a single post, and patterns give you reusable layouts to start from. These pages describe block themes; if your site uses a classic theme, see [Classic WordPress](../classic/README.md).

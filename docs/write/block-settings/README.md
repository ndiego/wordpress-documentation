# Block settings and design tools

When you select a block, the settings sidebar shows the design tools that block supports: color, typography, dimensions, border and shadow, background, layout, position and filters. Most blocks share the same tools, so each one is described once, here, instead of on every block page.

Which tools a block offers depends on the block and on your theme. If a setting described here is missing, the theme may have turned it off.

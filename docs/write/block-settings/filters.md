# Filters and duotone

Use the filter settings to change image appearance with a duotone overlay.

To apply a filter to an image, add a block containing an image, some examples are the [Image Block](../../blocks/media/image.md) or the [Cover Block](../../blocks/media/cover.md).

> [!NOTE]
> Refer to this article for [detailed instructions on adding blocks](../blocks/add-a-block.md).

## Using filters

While using a block with image, you can go to the **Style** tab and select a filter.

![Example of selected duotone filter](https://wordpress.org/documentation/files/2023/08/image.png)

The filter options provide several duotone preset to choose from. Alternatively, you can set the color for shadows and highlights yourself by clicking the color bar.

## Adding to Global Styles

It is also possible to add filters to Global Styles, you can see more about that on the [Styles Overview](../../design/site-editor/styles.md) page.

When selecting a block containing an image on Global Styles, you have the option to apply a specific filter by default on all existing and new images.

![Example of adding a duotone filter on the Global Styles](https://wordpress.org/documentation/files/2023/08/image-2.png)

## Reset options

While using the filter, you also have the option to revert whatever you want, this allow you to try and revert to experiement the image in different ways. To do so, click the **Filters options** button and select **Reset all**.

![Example of clicking on "Reset all" for a duotone filter](https://wordpress.org/documentation/files/2023/08/image-1.png)

## Supported blocks

The filter is currently avaliable in the following blocks:

-   [Image Block](../../blocks/media/image.md)
-   [Cover Block](../../blocks/media/cover.md)
-   [Gallery Block](../../blocks/media/gallery.md)

# Write and edit

This section helps you write, edit and publish content in WordPress. Everything you write happens in the block editor, where each paragraph, heading and image is a block. If you have never used it, start with [Create a post](create-a-post.md), which walks you through a complete post from a blank screen to publication. The pages below cover each part of writing in more depth.

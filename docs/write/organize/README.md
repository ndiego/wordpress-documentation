# Organize your content

WordPress gives you several ways to organize content so that visitors can find it: categories and tags group posts, post types separate posts from pages and other kinds of content, and custom fields add extra details to a post.

This group also covers two pages most sites need: a static front page and a search page. Start with [Categories](categories.md) if you write posts.

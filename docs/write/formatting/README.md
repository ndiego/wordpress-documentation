# Formatting

WordPress changes some of the text you type before it shows it to visitors: it turns quotes into curly quotes, smilies into images, and some characters into HTML entities. These pages explain what it changes and how to type characters that have a special meaning.

You rarely need them in the block editor; they matter most when something on the page looks different from what you typed.
